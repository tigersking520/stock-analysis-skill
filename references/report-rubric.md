# 报告质量自检表

## 完成前必须自检

| 检查项 | 合格标准 |
|---|---|
| 结论区分 | 明确区分公司质量、增长真实性、价格合理性 |
| 数据来源 | 核心数据有来源、日期、口径 |
| 财务排雷 | 包含净现比、销售回款率、应收、存货、大存大贷 |
| 估值测算 | 包含 PE/PS、情景估值、安全边际 |
| 逆向定价 | 高估值或暴增公司包含市值倒推和下一季度验证线 |
| 关键因子 | 包含红黄绿灯表和信息源 |
| 反证清单 | 明确列出能推翻当前结论的事实 |
| 风险提示 | 不构成投资建议，且风险不是空话 |

## 常见低质量问题

1. 只写行业空间大，不写公司能分到多少。
2. 只写利润增长，不看现金流和应收账款。
3. 只看 PE，不看 PS 和市值/收入匹配度。
4. 把高毛利率、高净利率线性外推。
5. 用新闻和研报替代公告原文。
6. 只给买入区间，不给反证条件。
7. 把“公司好”和“价格好”混成一个结论。

## 最终结论模板

推荐结论结构：

1. 公司是否优秀：一句话。
2. 增长是否真实：一句话。
3. 当前价格是否透支：一句话。
4. 后续最重要的验证指标：3-5 条。
5. 评级和策略：观望、跟踪、分批、回避等研究口径。
